# 反方笔记

## 二辩反驳计划（段5）

**投票故事**：我方赢，因为"全面推行"是对所有企业的强制，而场上唯一关于强制减时的因果证据（法国C8）显示，成本最终落在最低工资工人的岗位上；正方的产出证据全部来自自愿参加的企业。即便正方赢了"部分企业能消化成本"，我方仍赢：休息的前提是有工作，受损的2亿灵活就业者、中小企业80%城镇就业和青年求职者，范围更大、更难逆转。

**前线（正方一辩反驳 → 我方回应）**
- 论点二"算式假设产出少五分之一"：25%是每小时人工成本的算术；产出和钟点挂钩的岗位（流水线、门店营业时间、按单配送）效率补不回来。正方举的奶茶店、酒店恰恰是这类岗位 → 把"青年在服务业就业"的转向转回来。
- 正方产出证据：冰岛=缩短工时非四天（质询已承认）；英国61家仅23家提供收入数据、收入≠成本、自愿参加；NPR[P10]测的是倦怠和睡眠，不是成本或就业；C9：试点里企业量身设计的是方案本身，正方的法律恰恰统一了决定成本的两个数：工时和工资。
- "法国只有就业数据没有产出数据"：就业正是影响本身；C8是场上唯一一份"强制覆盖所有人"的证据。
- 1995双休：正方质询自己说"先从职工开始"；三十年后周均48.2小时[C1]——标准写进法律不等于落到人身上，反而证我方论点一。
- 5.66%/14.9%非唯一：我方从未说长工时导致它们；它们说明缓冲垫有多薄。
- 论点一"执法问题不是标准问题/40也该废？"：保留40、执行40，不在没人达标时把线挪更远。"33小时起付加班费"：今天超过标准工时就该付加班费（法律常识，作推理），周均仍48.2小时。
- 张华：正方质询承认保薪只针对有合同职工、不能一次覆盖所有人 → 2亿人拿不到"保薪"前提。

**进攻正方**
- 健康：不否认过劳伤身；P2讲的是55小时以上人群，正是40小时都没落实的人。新卡C10：正方引的同一份《提振消费专项行动方案》，休息权第一条是严格落实带薪年休假 → 中央答案是执行。
- 消费：断在"多一天=多花钱"。消费要时间也要钱；P7是五一这种集中假期；对灵活就业者多一天=少一天收入[C4]，对中小企业职工=缩招风险。

**权衡**：前提（有工作才有休息）+ 范围（2亿、80%、青年）+ 概率（强制证据C8 vs 自愿样本C9）。

**去留**：总结首选收拢论点二（就业，C8+C5+C6+C7），论点一作为支撑（C1+C2+C4，1995例子）。放弃细争冰岛86%的来源。
